# Practice Korean webfonts

These font files are self-hosted only for Korean learning content marked with
`lang="ko"`. They are unmodified upstream binaries from the
[Google Fonts repository](https://github.com/google/fonts) at the `main`
branch, downloaded on 2026-07-30.
