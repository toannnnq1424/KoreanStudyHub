### 19.4 R/L, Writing and Speaking target contracts

R/L v3 is reused, not replaced. A v4 strategy envelope adds
`strategyRegistryVersion`, `strategyCode` and a strategy fingerprint chosen by
the lecturer/backend before generation:

| Question type | Typed strategies/blocks |
|---|---|
| `SINGLE_CHOICE` | `EVIDENCE_ONLY`; `ELIMINATE_ALL_INCORRECT` reusing complete v3 `optionRationales`; `FULL_CONTEXT_THEN_ANSWER` using ordered backend-issued context segment IDs followed by answer evidence; `HYBRID` combining relevant context, answer evidence and every option rationale |
| `TFNG` | Typed `trueAnalysis`, `falseAnalysis` and `notGivenAnalysis`, each with Vietnamese reasoning and evidence IDs; `notGivenAnalysis` also carries typed missing-information text |
| `FILL_BLANK` | Stable blank IDs with typed context, semantic, grammar and register constraints plus evidence IDs and reconstructed Korean context/translation |

The provider never changes official answers or accepted values. The lifecycle
is generated `DRAFT` -> lecturer typed preview/edit -> `APPROVE` -> `PUBLISH`.
Approval binds actor/time and the exact draft/strategy/snapshot fingerprint;
any relevant edit invalidates approval. Learners read only the published
binding. Existing v3 artifacts remain read-only for their historical
published versions and are not rewritten.

Writing vNext preserves Q53 weights `12/9/9` and Q54 weights `20/15/15` while
adding versioned task/criterion score-level anchors. It adds:

- criterion judgments with anchor/descriptor, score, evidence IDs, finding
  IDs and evidence-linked feedback claims;
- an evidence ledger with stable IDs, exact text, UTF-16 offsets, occurrence
  index/count and normalization identity;
- stable provider artifact-local finding IDs, `MISSING|REPLACE|REDUNDANT`,
  error category, criterion, evidence IDs and requirement IDs;
- backend-owned `taskCoverage[]` as
  `{requirementId,status,evidenceIds}`; and
- evidence-linked summary claims instead of unaudited free-text authority.

Finding count remains score-independent. Scores must fit their anchor; a
maximum anchor cannot coexist under the same criterion with a major/blocking
negative finding; mandatory `MISSING` coverage cannot coexist with maximum
content fulfillment. The backend never silently changes a semantic score.
Whether one bounded repair call is allowed is a product decision; otherwise
contradictions fail closed. Stable finding/evidence IDs drive one-to-one
Writing answer spans and cards; malformed, duplicate or overlapping spans
continue to fail closed.

Speaking keeps its current safe transcript-only boundary. Transcript evidence
may support grammar, vocabulary/collocation, lexical repetition, register and
coherence. Pronunciation, stress, phoneme, rhythm, pauses, delivery and
audio-dependent fluency remain `NOT_SCORABLE`; the evaluator receives no
learner audio bytes or URL. Direct-audio/acoustic assessment, alignment,
consent/privacy/retention and realtime speech are separate
`DEFER_PRE15` work, first blocked by product and Korean-calibration decisions.
