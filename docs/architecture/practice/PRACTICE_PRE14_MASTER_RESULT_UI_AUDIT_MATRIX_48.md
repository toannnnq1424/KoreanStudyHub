## Reading guide

Every row records the requested audit dimensions in compact form:

- **Macro / header / catalogue**: canvas and pane hierarchy; navigation/header; tabs, chips, question groups, and state shown.
- **Visual / ownership**: typography and icon style; radius, border, shadow, palette, spacing, density; scroll owner, sticky regions, splitter, and responsive behavior.
- **Boundary / sequence**: what belongs in Overview versus Detail and the PREP interaction that produced the image.
- **Delta S/B/V/C**: `S` structural, `B` behavioral, `V` visual, `C` contract/backend.
- **Viewport**: the first value is the target browser CSS viewport. `ref` is the source bitmap size. Most full PREP captures are approximately 2x device scale; the four 2026-07-05 Speaking crops are 1x reference crops.
- Query fragments such as `tab=...` below describe deterministic browser interaction state, not a server URL contract. The stable seed URL remains the path before the fragment.

Common visual reference for full-screen PREP Result pages: one blue canvas, one large white result sheet, moderate 12–16 px radii, very light dividers/shadows, restrained tints, generous 24–32 px whitespace, one dominant reading hierarchy, Lucide-equivalent SVG icons, and independent pane scrolling where Detail requires it.
